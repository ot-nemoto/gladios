# gladios — 剣闘士オートバトルゲーム

古代ローマの闘技場を舞台にした、1対1の自動戦闘ゲームを開発しています。

現在は攻撃・防御モーションと、その接続を中心に戦闘を再設計しています。[公開ページ](https://ot-nemoto.github.io/gladios/)で、棒人間による攻防の動くサンプルを見られます。

1つの戦闘表示で、連続攻防・空振り後の3展開に加え、盾で上へそらす・剣で受け止める・盾の面で押すケースをタブで切り替え、通常・低速で再生できます。左右の使用スキル（仮称）を表示し、動作に合わせて使用中のスキルを強調します。展開は固定の演出で、能力値・命中・ダメージ・勝敗の判定はまだありません。旧戦闘ロジックやPython試作は削除済みです。

## 手元で開く

Node.js 24 が必要です。

```sh
npm ci
npm run dev
```

http://localhost:5173/ で同じサンプルが開きます。

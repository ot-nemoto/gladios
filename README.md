# gladios — 剣闘士オートバトルゲーム

古代ローマの闘技場を舞台にした、1対1の自動戦闘ゲームを開発しています。

現在は攻撃・防御モーションと、その接続を中心に戦闘を再設計しています。旧戦闘ロジック・戦闘ビューア・モーション図鑑・Python試作は削除し、Vite＋TypeScriptの土台と準備中のページを残しています。新しい戦闘はまだ実装していません。

## 手元で開く

Node.js 24 が必要です。

```sh
npm ci
npm run dev
```

http://localhost:5173/ で準備中のページが開きます。

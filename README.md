# gladios — 剣闘士オートバトルゲーム

古代ローマ（紀元80年頃）の闘技場を舞台に、**剣闘士本人として戦う 1 対 1 の自動戦闘ゲーム**です。
プレイヤーは戦闘中に操作せず、事前に「装備」と「作戦（条件 → 行動のルール）」を組み立てます。戦闘はその作戦どおりに自動で進み、結果とログから勝因・敗因を分析して、作戦と育成を改善していきます。

> 開発中です。今は戦闘の仕組みを確かめるための 2 つの画面が動きます（下記）。作戦の設定、育成、ドット絵のグラフィックスはこれからです。

## ゲームの特徴

- **運ではなく、動きで勝負が決まる**：命中率のような確率は使いません。剣の軌道、間合い、タイミング、体勢で結果が決まり、同じ条件なら必ず同じ結果になります（リプレイも完全に再現できます）。
- **当たり判定は体の形そのもの**：剣闘士を横から見た 2 次元で、頭・胴・腕・脚と盾を図形として扱い、剣の線分が最初に触れた部位に当たります。盾の下を抜けて脚を斬る、腕を上げた隙に胴を突く、といったことが形どおりに起きます。
- **防御は方針を選ぶ**：受け止める・受け流す・回避する、から作戦で選びます。相手の構えを見て反応し、大きな攻撃ほど読みやすく、外したときの隙も大きくなります。
- **消耗と負傷**：スタミナ、体勢の崩れ、部位ごとの負傷が積み重なり、動きの速さや判断に影響します。
- **史実に寄せた装備**：武器 5 種（グラディウス、スィカ、プギオ、トライデント、ハスタ）、盾 3 種（スクートゥム、パルムラ、小盾）、防具 5 種。ファンタジー要素はありません。

## 今できること

公開ページ：https://ot-nemoto.github.io/gladios/

### 戦闘ビューア

確認用の戦闘（25 種類）を選んで、自動戦闘の様子を再生できます。

- 剣闘士は当たり判定の図形そのままで描かれ、命中した側は光り、盾や剣で受けた側は盾の縁が光ります。
- 再生・一時停止・速度変更（×0.1〜×8）・シーク、前後のイベントへのジャンプ。
- 両者の体力・スタミナ・体勢のゲージと、今の行動。
- 戦闘ログ（行動開始・接触・結果・状態の変化）を剣闘士と種類で絞り込め、行をクリックするとその時刻へ飛びます。
- 「判定領域」をオンにすると、当たり判定の輪郭と関節を重ねて表示します。

操作：Space 再生／停止、← → 0.1 秒送り（Shift で 1 秒）、[ ] 前後のイベント

### モーション図鑑

https://ot-nemoto.github.io/gladios/motions.html

攻撃・防御・移動などの動作（88 種類）を 1 つずつ選び、どう動き、いつ相手のどこに当たるかを確かめられます。

- 動作を実際の秒で再生・シーク（×0.05〜×1）。剣先の軌道を「準備・実行・完了直前」の段階で色分けし、基準になる姿勢（キーフレーム）を残像で重ねます。
- 相手の盾・姿勢（構え、受け止め、受け流し、回避）・間隔を変えると、届くか、盾に先に当たるか、最初に何秒で相手のどこに触れるかが変わります。
- 段階とキーフレームと接触を並べたタイムライン、キーフレームのサムネイル、関節の角度のグラフ、数値の表。
- 表示中の動作と条件は URL に残るので、リンクで共有できます。

操作：Space 再生／停止、← → キーフレーム間、`,` `.` 0.005 秒送り、↑ ↓ 動作の切り替え

## 手元で動かす

Node.js 24 が必要です。

```sh
npm install
npm run dev
```

http://localhost:5173/ で戦闘ビューア、http://localhost:5173/motions.html でモーション図鑑が開きます。

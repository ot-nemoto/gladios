# gladios — 小さな装備室

低頭身の女性剣闘士の兜を切り替えて見比べる着せ替え見本です。[公開ページ](https://ot-nemoto.github.io/gladios/)で試せます。

「兜なし」「銀・青緑の兜」「黒金・紫の兜」の3種類を選べます。「兜を外す」で基本の姿に戻り、選んだ立ち絵をPNGで保存できます。スマートフォンでも表示できます。

全身画像3枚を切り替える方式で、装備パーツの合成やモーション・戦闘判定はありません。

## 手元で開く

Node.js 24 が必要です。

```sh
npm ci
npm run dev
```

http://localhost:5173/ で同じ着せ替え見本が開きます。

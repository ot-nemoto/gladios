# Gladios

剣闘士のキャラと背景を選んで重ね、1枚の画像として保存できるアプリです。[公開ページ](https://ot-nemoto.github.io/gladios/)で試せます。

背景透過のキャラ29種（TADALA、MARCUS MARIUS AVITUS、BERENICE、CASSIA、GOLD HILDR、VLATTIA、SPATALIA、KRIMHARTH、BRANTHOC、TUKHORIS、KASOS、THALES、KHNUBA、MEDOCUS、GAIUS PONTIDIUS STOLO、SALOMON、AMBILLUS、EATHYROSS、AKILIAS、IGRAINE、OWAIN、IGNATIUS、GODFREY、GALERON、ENOCH、ELIJAH、ANDREW、ADALRIC、GWENDOLYNNE HEAVENSBRAND）と、背景28種（海、雪原、草原、森、湿地、山、街、洞窟、松と金雲、鶴と青海波、桜と金屏風、竹と金月、梅と金の雪、富士の裾と金雲、鯉と滝、紅葉と金流水、大聖堂のバラ窓、ゴシック尖頭アーチ、中世グリザイユ、夜の大聖堂、藤とトンボ、バラ園アーチ、海と帆船、ケルト結び目、孔雀の羽、葡萄と秋の葉、蓮と水、星座の円環）から1つずつ選ぶと、背景の上にキャラを重ねて表示します。表示中の組み合わせは、512×512のPNGとして保存できます。スマートフォンでも使えます。

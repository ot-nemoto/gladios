# 他のLLMへの依頼テンプレート

「今回の変更」を記入し、リポジトリの接続先、または共有ZIPと一緒に以下を渡す。まだ何を追加するか決めていない場合は、実装を依頼せず相談内容を書く。

```text
gladios（キャラと背景の合成アプリ「Gladios」）の変更をお願いします。返答は日本語で。

今回の変更：
［ここに、追加・変更したいことを1つ記入］

確認したい結果：
［操作と、期待する見た目・動作を記入］

共有したコミットID：
［ZIPはGitHubへpush済みのHEADで作り、git rev-parse HEADの結果を記入。
 develop以外ならブランチ名またはPRのURLも記入。リポジトリ接続時はdevelopを確認］

まず以下を読んでください。
- AGENTS.md
- docs/development.md（開発規則の正本）
- docs/引き継ぎ.md（現行構成・素材の追加手順・確認方法）
- docs/01_基本設計書.md（現在の仕様・未決事項・確認の範囲）

公開対象はトップの1ページだけです。
背景透過のキャラと背景を1つずつ選んで重ね、512×512のPNGとして保存できます。
キャラ・背景は src/scene-data.ts に定義し、素材は src/assets/scene/ にあります。
キャラは可逆のwebp、背景は画質90のwebpで置き、選択欄には縮小画像を使います。

今回の変更に必要な範囲で進めてください。
仕様判断・変更管理・検証結果の記録は、上記の開発ガイドに従ってください。

ファイル編集・実行・GitHub操作・Claude Codeによるレビューのうち、
この環境でできないことがあれば明示し、できる範囲の変更案や差分を用意してください。
実行していない検証やレビューを完了したと報告しないでください。

最後に、変更内容・実施した確認・未確認事項・PRまたは差分の場所を簡潔に教えてください。
```

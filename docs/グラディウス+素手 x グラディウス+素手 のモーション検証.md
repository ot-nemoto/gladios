# グラディウス+素手 x グラディウス+素手 のモーション検証

## 1. 今回の範囲

**双方とも、右手にグラディウスを保持し、左手は素手とする。盾は持たない。**

- 「素手」は左手に装備を持たないことを指す。武器なし同士の対戦ではない。右手の剣を持ち替えたり手放したりする動作は追加しない。
- パルムラ同士とは別の検証文書とし、この2組を混ぜた対戦は扱わない。
- 目的は「攻撃→防御→結果後の双方の姿勢→次の攻防」のつながりを点検すること。まず剣の基本動作と、空いた左手を使う候補を整理する。
- 動作は候補であり、技の採用・身体的成立・成功を確認したものではない。投げ・転倒等の詳細には進まない。

## 2. モーションの候補一覧

左右は各動作を行う本人の開始時の向きを基準にする。左手は、装備を持たないことに加え、保持・拘束・支持に使われていない場合に空き手として扱う。

| 攻撃候補 | 動き | これから具体化すること |
|---|---|---|
| 剣で突く | 右手の剣先を対象へ進める | 高さ・間合い、右腕・剣・左手の経路、引き戻し |
| 剣で左へ斬る | 本人の右側から左側へ振る | 刃の向き、左手との干渉、振り抜いた後 |
| 剣で右へ斬る | 本人の左側から右側へ振る | 反対向きの経路、左手との干渉、切り返すまで |
| 左手で打つ | 空いた左手を対象へ出す | 拳・掌等の接触部位、対象、届く間合い、右手の剣と戻りの経路 |

| 防御候補 | 動き | これから具体化すること |
|---|---|---|
| 剣で受け止める | 右手の剣で相手の攻撃を受ける | 剣の接触部位、止まる対象、双方の腕・剣・身体 |
| 剣でそらす | 相手の剣を本人の右／左へそらす候補を別々に調べる | 交差する剣、相手の剣先の移動、接触解除と反撃の経路 |
| 左手で武器腕を制御する | 空いた左手で相手の右手首・腕へ接触する候補 | 到達するまでの攻撃線と時刻、掴む対象と範囲、制御の継続。刃を素手で受ける候補とはしない |
| 後方へ避ける | 本人の後ろへ移動する | 後退の余地、突きの追従、双方の間合い |
| 右へ避ける | 本人の右へ移動する | 移動中も残る攻撃線、双方の向きと剣・左手 |
| 左へ避ける | 本人の左へ移動する | 右回避とは別の位置関係、双方の向きと剣・左手 |

一覧は基本動作から整理した初稿であり、網羅性は未確認。方向・高さの違いを全て完成モーションとして数えない。

## 3. 最初の点検：Aの胴への突きにBが対応する

A・Bは向かい合う二人で、双方の装備は §1 のまま。具体姿勢・間合い・軌道・時刻は未設定。以下は結果を仮定した条件点検であり、その結果が生じることや防御成功を確認した表ではない。

| 仮定する結果 | Aの次の候補と必要な移行 | Bの次の候補と必要な移行 | 今回分かったこと／未確認 |
|---|---|---|---|
| Bの剣でAの剣の前進が止まる | 接触を離し、引き戻して突き直す候補 | 受けた右剣を攻撃へ移す／空いた左手で対応する候補 | 同じ剣同士の接触を維持しながら離すことは指定しない。停止位置、右腕・身体の動き、接触解除の経路・時間は未確認 |
| Bの剣との接触でAの剣が戻る側へ動く | 戻る動きから左斬り／右斬りへ移る候補 | 右剣の位置を整え、反撃する候補 | 止まる場合とは別に点検する。戻る方向と、次の斬りの開始姿勢は未確認 |
| Bの剣でAの剣がB本人の右へそらされる | Aから見た左側へそらされた剣から次の動きへ移る候補 | 右側へ動いた剣の接触を離して反撃する／接触を続ける候補を分ける | 向きを変えなければBの右はAの左側。双方の右剣と左手の干渉、次の剣の経路は未確認 |
| Bの剣でAの剣がB本人の左へそらされる | Aから見た右側へそらされた剣から次の動きへ移る候補 | 左側へ動いた剣の接触を離して反撃する／接触を続ける候補を分ける | 前行とは別の経路。向きを変えなければBの左はAの右側。右そらしと同じ接続にはせず、双方の右剣と左手の干渉は未確認 |
| Bの左手がAの右手首を保持する | 空いた左手で解除を試みる／制限内で剣を動かす候補 | 左手の保持を続け、右剣で突く複合動作の候補 | 保持中のB左手は空き手ではなく、同時に空いた左手の打撃へ使えない。A右手の剣保持と外からの拘束は別。掴むまで・解除・複合動作の成立は未確認 |
| Bが後方へ避け、突きが当たらない | 剣を戻し、距離に応じて追う／構え直す候補 | 後退後の間合いから反撃する／距離を保つ候補 | 後退だけで回避成功としない。双方の到達と時刻は未確認 |
| Bが本人の右へ避け、突きが当たらない | Aから見た左側の相手へ剣を向ける／斬りへ移る候補 | 右移動後の位置から向きを整え、剣で反撃する候補 | 向きを変えなければB右はA左。残る突きの軌道、双方の向き直りと到達は未確認 |
| Bが本人の左へ避け、突きが当たらない | Aから見た右側の相手へ剣を向ける／斬りへ移る候補 | 左移動後の位置から向きを整え、剣で反撃する候補 | 向きを変えなければB左はA右。前行とは別の経路として点検し、役割を替えても装備の左右は反転しない。実際の接続は未確認 |

各行は排他的な分類ではない。停止後の弾き返し等の時間経過・複合結果も今後の点検対象に残し、実際の連続動作は未検証。防御が間に合わず身体へ届く場合や、途中の再接触も未検証。

## 4. 確認結果

- ✅ 全候補で双方の右手に剣・左手に装備なしという前提を保ち、盾の動作を流用していない。
- ✅ 左手を保持・拘束・支持に使っている間は自由な手として別の動作に割り当てない。保持を続ける反撃は、全身の複合動作として別途具体化する候補にした。
- ✅ 本人基準の左右と、相手から見た左右を区別した。瞬時の姿勢戻しや、同じ接触の同時維持・解除を成立扱いしていない。
- 具体的な姿勢・軌道・力・時間がないため、接触・制御・解除・防御成功・連続動作の身体的成立は未検証。
- 剣を持ちながら左手を使う動作を、既存実装のテストや盾なしの見た目だけで検証済みとはしない。

## 5. 次に決めること

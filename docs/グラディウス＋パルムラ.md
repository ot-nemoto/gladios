# グラディウス＋パルムラ

装備別のモーション一覧。対戦組み合わせ別の文書と見比べるための比較用です。整理方式も個々の技も、まだ採用決定ではありません。

**右手：グラディウス／左手：パルムラ。**

以下は既存の検討資料から抜き出した候補です。「可能」と確認できた一覧ではなく、開始条件・動作後の状態も検討案です。身体的な成立・具体姿勢・軌道・時間は未検証。左右は動作開始時の本人基準です。両手の装備を保持したまま点検します。

## 攻撃

| モーション候補 | 使う部位・道具 | 開始時に必要な条件 | 動作後の姿勢・状態の案 |
|---|---|---|---|
| 剣で突く | 右手・剣先 | 剣先を対象へ進める経路。右腕・剣と左手の盾が干渉しない位置 | 右腕と剣を前へ出した状態。盾の位置と剣を戻す経路を確認する |
| 剣で左へ斬る | 右手・刃 | 本人の右側から左側へ振れる剣の位置と、盾に遮られない経路 | 剣を左側へ振った状態。剣と盾の位置、切り返す動きを確認する |
| 剣で右へ斬る | 右手・刃 | 本人の左側から右側へ振れる剣の位置と、盾に遮られない経路 | 剣を右側へ振った状態。剣と盾の位置、切り返す動きを確認する |

## 防御・回避

| モーション候補 | 使う部位・道具 | 開始時に必要な条件 | 動作後の姿勢・状態の案 |
|---|---|---|---|
| 盾で受け止める | 左手・パルムラ | 攻撃線を遮る盾の位置と接触部位を特定する | 盾を受ける位置へ置いた状態。停止・反動・右腕と身体の動きは未判定 |
| 盾で上へそらす | 左手・パルムラ | 上へそらす接触と盾の経路を作れるか確認する | 動かした盾・左腕と右剣の位置、接触の継続・解除を確認する |
| 盾で右へそらす | 左手・パルムラ | 本人の右へそらす接触と盾の経路を作れるか確認する | 右へ動かした盾と、右手の剣・身体との位置関係を確認する |
| 盾で左へそらす | 左手・パルムラ | 本人の左へそらす接触と盾の経路を作れるか確認する | 左へ動かした盾と右手の剣・身体を確認する。右そらしとは別に点検する |
| 剣で受け止める | 右手・剣 | 受ける剣の部位と位置、左手の盾との関係を特定する | 剣を受ける位置へ置いた状態。実際の停止・反動・接触継続は未判定 |
| 剣で右へそらす | 右手・剣 | 本人の右へそらす剣の経路と、盾との干渉を確認する | 右へ動かした剣と盾の位置、接触を離す・続ける条件を確認する |
| 剣で左へそらす | 右手・剣 | 本人の左へそらす剣の経路と、盾との干渉を確認する | 左へ動かした剣と盾の位置から確認する。右そらしと同じ終わり方にはしない |
| 後方へ避ける | 足運び・全身 | 後退する空間と足の支持があるか確認する | 後退後の位置・向き、剣と盾の配置を確認する |
| 右へ避ける | 足運び・全身 | 本人の右へ移動する経路と足の支持を確認する | 右移動後の位置・向き、剣と盾の配置を確認する |
| 左へ避ける | 足運び・全身 | 本人の左へ移動する経路と足の支持を確認する | 左移動後の位置から確認する。剣と盾の左右は反転しない |

## この一覧で見ること

- 「この装備の自分が何を行うか」と、その前後の状態を一覧で見る。
- 高さ・間合い・握り・足位置の詳細や、戻しに要する時間はこれから具体化する。
- 左手は盾を保持しているので、空いた左手による打撃・掴みの候補は入れない。
- 相手の攻撃に対応できるか、接触後にどの動作へつながるかは、対戦組み合わせ別の文書で点検する。盾や剣を動かすことと防御成功は別。
- 盾による打撃・押しなどは未整理。候補の網羅性は未確認で、ここにない動作を不可能・不採用とは扱わない。

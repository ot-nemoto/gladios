# Gladios 基本設計書

キャラと背景を合成するアプリ「Gladios」の現在の仕様と未決事項をまとめる。開発規則は [開発ガイド](development.md)、実装の詳細は [引き継ぎ資料](引き継ぎ.md) を参照。

## 1. 目的

剣闘士のキャラと背景を選んで重ね、1枚の画像として保存できるブラウザのアプリ。合成以外の機能は持たない。

## 2. 現在の仕様

- 公開ページはトップ（`/`）の1ページだけ。見出しとタブのタイトルは「Gladios」で、小見出し・説明文・他のページへのリンクは置かない。Vite + TypeScriptで実装し、developからGitHub Pages（https://ot-nemoto.github.io/gladios/ ）へ配信する。
- 背景透過のキャラ29種（TADALA、MARCUS MARIUS AVITUS、BERENICE、CASSIA、GOLD HILDR、VLATTIA、SPATALIA、KRIMHARTH、BRANTHOC、TUKHORIS、KASOS、THALES、KHNUBA、MEDOCUS、GAIUS PONTIDIUS STOLO、SALOMON、AMBILLUS、EATHYROSS、AKILIAS、IGRAINE、OWAIN、IGNATIUS、GODFREY、GALERON、ENOCH、ELIJAH、ANDREW、ADALRIC、GWENDOLYNNE HEAVENSBRAND）と背景28種（海、雪原、草原、森、湿地、山、街、洞窟、松と金雲、鶴と青海波、桜と金屏風、竹と金月、梅と金の雪、富士の裾と金雲、鯉と滝、紅葉と金流水、大聖堂のバラ窓、ゴシック尖頭アーチ、中世グリザイユ、夜の大聖堂、藤とトンボ、バラ園アーチ、海と帆船、ケルト結び目、孔雀の羽、葡萄と秋の葉、蓮と水、星座の円環）から1つずつ選び、背景の上にキャラを重ねて表示する。初期表示はTADALA×海。
- 表示中の組み合わせを512×512のPNGとして保存できる。ファイル名は `gladios-<キャラのid>-<背景のid>.png`。
- 素材はキャラ・背景とも512×512で揃え、位置や大きさの調整はしない。
- 背景はwebp（画質90は仮置き）で置き、PNGなどで受け取った背景は変換する。キャラはファイルの画素を変えない可逆のwebp（透過あり）で置き、PNGなどで受け取ったキャラは変換する。ブラウザでは、半透明の縁の画素がPNGと最大1階調変わることがある。
- キャラ・背景の選択欄はそれぞれ1行に並べ、はみ出した選択肢は横スクロールで選ぶ。PCでは選択肢を3つ半（右の列が狭い幅761〜960pxでは2つ半）、幅760px以下の1列表示では4つ半が見える大きさにし、右端の欠けで続きを示す（見える数・欄の余白6pxは仮置き）。長い名前は単語の途中でも折り返し、ボタン内に収める。
- 選択欄のサムネイルには256×256の縮小画像を使い、合成と保存には512×512の元画像を使う（大きさ・画質は仮置き）。サムネイルは段階的に読み込む。各欄のスクロール位置で見えている範囲と左右に欄の幅1つ分の先まで（画面外の欄も含む）を先に読み、欄が初めてスクロールされたらその欄の残りを読み、それ以外の残りはページの読み込み後に、選んだキャラ・背景の表示を妨げないよう少しずつ読む（先読みの範囲・同時に読む枚数は仮置き）。

## 3. 未決のこと

- 次に追加するキャラ・背景と、位置・大きさの調整を行うかどうか。
- 合成した画像を、URLの指定（GET）で取得できるようにするかどうか。GitHub Pagesでは合成処理を動かせないため、外部サービス（Netlify Functions、AWS Lambda ＋ CloudFront など）で合成する案を検討中で、方式・費用の上限・アカウントは未決定。

これらは未採用の検討事項であり、実装する場合は個別に内容を決める。

## 4. 確認の範囲

- 全組み合わせの表示・保存（保存PNGが素材を重ねた画像と一致すること）は、Chromiumで確認する。
- 実機では、iOS Safari で表示・操作と保存を目視で確認している。
- Safari での全組み合わせの保存一致、Safari での半透明の縁の画素比較、遅い回線での実機のスワイプとサムネイル表示、macOS の Safari、Android の Chrome は、確認の対象外とする（未検証）。

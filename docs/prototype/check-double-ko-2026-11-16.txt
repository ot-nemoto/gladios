# 確認記録：相打ち（引き分け）（設計書 v3.45、Issue #10）

記録日：2026-11-16

## 変更
- 同じ刻み（0.005 秒）の中で両者の体力が 0 以下になった場合は、相打ち（引き分け）とし勝者を決めない。
- それまでは終了の判定を A → B の順に行っていたため、相打ちは必ず B の勝ちになっていた。

## 結果が変わったシナリオ

| シナリオ | 変更前 | 変更後 |
|---|---|---|
| 自動選択: 斬る・鏡合わせ | B の勝ち 82.73秒 | 相打ち 82.73秒 |
| 自動選択: Bはすね当てなし | B の勝ち 82.73秒 | 相打ち 82.73秒 |
| 装備: 武器のみ同士・受け流し | B の勝ち 96.70秒 | 相打ち 96.70秒 |

他の 21 シナリオは、ログ・結果・最終状態とも変更前と完全に同じ。

## 所見
- 変わった 3 シナリオはいずれも、最後の命中で両者の体力が同時に 0 以下になっていた（例：斬る・鏡合わせは 82.73 秒に両者の脚へ命中し、両者とも体力 -6）。終了のログは「両者の体力が0。相打ち（引き分け）」。
- 決定論：同じ条件の再実行でログが完全一致。TS の移植は全シナリオで Python と完全一致。

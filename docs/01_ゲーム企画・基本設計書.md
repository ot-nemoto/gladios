# 小さな装備室 基本設計書

現在開発する装備室の範囲と未決事項をまとめる。§12・§14は既存の参照を保つための節番号で、番号の間に省略された現行仕様はない。開発規則は [開発ガイド](development.md)、実装の詳細は [引き継ぎ資料](装備室_引き継ぎ.md) を参照。

## 1. 目的

低頭身の女性剣闘士の装いを切り替え、見た目を楽しみながら比べるブラウザの着せ替え見本。今はこの装備室を小さく拡張していく。

## 2. 現在の仕様

- 公開ページは装備室の1ページ。Vite + TypeScriptで実装し、developからGitHub Pagesへ配信する。
- 「兜なし」「銀・青緑の兜」「黒金・紫の兜」「金・赤の兜」「銀・角付きの兜」の承認済み全身画像5枚を切り替える。初期表示は銀・青緑。
- 「兜を外す」で兜なしへ戻り、選択中の元の全身PNGを保存できる。
- 画像ごとの腰・足裏の基準を使って表示位置と大きさを調整する。スマートフォンでも操作できる。
- 現在は全身画像の切替方式。兜・武器・防具の独立したパーツ合成、モーション、戦闘判定は未実装。
- 既存の棒人間サンプルのコードは残るが、公開ページと公開用ビルドには読み込まない。

## 3. 拡張で未決のこと

- 次に追加する装備と、その画像の制作方法。
- 全身画像の切替を続けるか、独立した装備パーツを合成するか。
- 素材の画素密度・キャンバス・接地基準の統一方法（[#105](https://github.com/ot-nemoto/gladios/issues/105)）。
- 候補が増える際のデータ定義・件数表示の重複整理（[#108](https://github.com/ot-nemoto/gladios/issues/108)）。

これらは未採用の検討事項であり、実装する場合は個別に内容を決める。

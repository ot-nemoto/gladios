# 小さな装備室 基本設計書

現在開発する装備室の範囲と未決事項をまとめる。§12・§14は既存の参照を保つための節番号で、番号の間に省略された現行仕様はない。開発規則は [開発ガイド](development.md)、実装の詳細は [引き継ぎ資料](装備室_引き継ぎ.md) を参照。

## 1. 目的

低頭身の女性剣闘士の装いを切り替え、見た目を楽しみながら比べるブラウザの着せ替え見本。今はこの装備室を小さく拡張していく。

## 2. 現在の仕様

- 公開ページは装備室の3ページ。`/` は元の画像切替版、`/equipment.html` は装備着脱版、`/helmet-fit.html` は元の顔と兜のサイズ比較で、相互リンクを備える。Vite + TypeScriptで実装し、developからGitHub Pagesへ配信する。
- 元の画像切替版では「兜なし」「銀・青緑の兜」「黒金・紫の兜」「金・赤の兜」「銀・角付きの兜」「金・一本角の兜」「黒・赤い鶏冠の兜」の承認済み全身画像7枚を切り替える。初期表示は銀・青緑。
- 画像切替版は「兜を外す」で兜なしへ戻り、選択中の元の全身PNGを保存できる。
- 装備着脱版は同じ人物に6種類の独立した兜PNGを重ねる。初期表示は銀・青緑。装備時は低いポニーテール、外すと元の顔・髪型へ戻る。共通人物の首・襟足・肩を保持し、兜の選択によって体の大きさを変えない。
- 着脱版の選択欄は兜単体の画像6種類から選ぶ。「兜なし」は「—」を表示する。人物が着けた姿は大きなプレビューで確認する。
- 着脱版の保存対象は人物と兜を合成した1086×1708の透過PNG。兜なしも同じキャンバスで、飾りが収まるよう上側に260pxの余白を持つ。
- 着脱版の金・一本角は、採用した短い角と、銀・角付きに合わせた頭部サイズ・その後の約4%拡大を反映する。黒・赤は鶏冠を高くしたパーツを使う。
- 着脱版の銀・角付き／金・一本角／黒・赤い鶏冠は、銀・青緑を目安に顎当ての下端を顎先より少し下へ出す。頭部サイズ・共通人物と黒・赤の鶏冠は維持する。金・一本角の角先と両兜の襟足は、次項の承認済み調整を適用する。元の画像切替版は別の全身素材を使う。
- 着脱版の銀・角付きは耳と襟足を広く覆い、頬から襟足まで継ぎ目のない銀板としてつなげる。金・一本角は襟足の覆いと外へ反った縁を低い位置に置き、縁を浅くして襟足側の濃い茶色を抑える。角先は画像の右へ少し曲げる。通常の着用では髪の根元を奥側の縁より手前につなぎ、毛先の位置は保持する。どちらも承認済みのパーツを使用し、頭部サイズ・顔の開口部・共通人物を維持する。
- サイズ比較ページは基準の顔と各兜の顔周りを同じ座標・倍率で並べる。通常表示と元の顔への半透明表示、頭頂・額・後頭部・耳側・鼻先・目・顎・兜の端の基準線のON/OFFを切り替えられる。ラベル文字のON/OFFは別に切り替えられ、初期表示では線・文字ともに表示する。線を隠すと文字も隠れて文字切替を無効にし、線を再表示したときは文字の選択状態を保つ。ラベルは「頭頂」「額」「後頭部」「耳側」「鼻先」「目」「顎」「兜の端」とし「（目安）」を付けない。「後頭部」「耳側」「鼻先」「兜の端」の文字は、画像上端の対応する縦線の位置に沿って左からこの順に置く。文字が画像に重ならないよう上側にラベル欄を設け、小さな枠でははみ出さず折り返す。文字や線の非表示時も上側欄の高さを保ち、画像の上下位置を変えない。基準線は表示サイズによらず一定の太さで重ねる。頭頂は髪を含む目安。額の横線は目から顎までと同じ距離だけ目の上に、後頭部の縦線は比較枠の左端と耳側の線の中間に置く。兜の端の縦線は、鼻先から比較枠右端までを3等分した鼻先寄りの位置に置く。いずれも補助的な目安で、実際の頭蓋骨の輪郭を確定するものではない。線は兜ごとに動かさない。
- 比較対象は着脱版と同じ装備データから取得する。新しい兜を装備データへ追加すると、比較画面にも名前・画像・髪の位置が反映される。通常の合成処理も着脱版と共通にする。比較ページから装備画像を編集する機能は設けない。
- 画像ごとの腰・足裏の基準を使って表示位置と大きさを調整する。スマートフォンでも操作できる。
- PCの2列表示では、選択肢をスクロールしてもプレビューが画面内に追従する。スマートフォンの1列表示は通常のページスクロールとする。
- 兜のパーツ合成は比較用の着脱版で提供する。武器・防具の着脱、モーション、戦闘判定は未実装。
- 既存の棒人間サンプルのコードは残るが、公開ページと公開用ビルドには読み込まない。

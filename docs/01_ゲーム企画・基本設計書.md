# 小さな装備室 基本設計書

現在開発する装備室の範囲と未決事項をまとめる。§12・§14は既存の参照を保つための節番号で、番号の間に省略された現行仕様はない。開発規則は [開発ガイド](development.md)、実装の詳細は [引き継ぎ資料](装備室_引き継ぎ.md) を参照。

## 1. 目的

低頭身の女性剣闘士の装いを切り替え、見た目を楽しみながら比べるブラウザの着せ替え見本。今はこの装備室を小さく拡張していく。

## 2. 現在の仕様

- 公開ページは装備室の4ページ。`/` は元の画像切替版、`/equipment.html` は装備着脱版、`/helmet-fit.html` は元の顔と兜のサイズ比較、`/scene.html` はキャラと背景の組み合わせで、相互リンクを備える。Vite + TypeScriptで実装し、developからGitHub Pagesへ配信する。
- 元の画像切替版では「兜なし」「銀・青緑の兜」「黒金・紫の兜」「金・赤の兜」「銀・角付きの兜」「金・一本角の兜」「黒・赤い鶏冠の兜」の承認済み全身画像7枚を切り替える。初期表示は銀・青緑。
- 画像切替版は「兜を外す」で兜なしへ戻り、選択中の元の全身PNGを保存できる。
- 装備着脱版は同じ人物に6種類の独立した兜PNGを重ねる。初期表示は銀・青緑。全ての兜で着用時の後ろ髪を兜の中へ収め、外へ出さない。外すと元の顔・髪型へ戻る。共通人物の首・肩の形と体格を保持し、兜の選択によって体の大きさを変えない。
- 着脱版の選択欄は兜単体の画像6種類から選ぶ。「兜なし」は「—」を表示する。人物が着けた姿は大きなプレビューで確認する。
- 着脱版の保存対象は人物と兜を合成した1086×1708の透過PNG。兜なしも同じキャンバスで、飾りが収まるよう上側に260pxの余白を持つ。
- 着脱版の金・一本角は、採用した短い角と、銀・角付きに合わせた頭部サイズ・その後の約4%拡大を反映する。黒・赤は一本角の帽体・顔の覆いを基準に整えた承認済みパーツと高い赤い鶏冠を使い、鼻当てがまっすぐな形を採用する。
- 着脱版の銀・角付き／金・一本角／黒・赤い鶏冠は、銀・青緑を目安に顎当ての下端を顎先より少し下へ出す。銀・角付きと金・一本角の頭部サイズ・共通人物は維持する。黒・赤は後述の #143 の承認済み調整を適用する。金・一本角の角先、および銀・角付きと金・一本角の襟足は、次項の承認済み調整を適用する。元の画像切替版は別の全身素材を使う。
- 着脱版の銀・角付きは耳と襟足を広く覆い、頬から襟足まで継ぎ目のない銀板としてつなげる。金・一本角は襟足の覆いと外へ反った縁を低い位置に置き、縁を浅くして襟足側の濃い茶色を抑える。角先は画像の右へ少し曲げる。着用時の後ろ髪は他の兜と同様に非表示とする。どちらも承認済みのパーツを使用し、頭部サイズ・共通人物を維持する。銀・角付きの鼻当て・縦帯と顔まわりは次項の調整を適用する。
- 着脱版の銀・角付きは、鼻当ての先をまっすぐにし、その位置に頭頂から続くリベット付き縦帯を合わせる。右側輪郭と額の独立した黒点を整理した承認済みパーツを使う。局所合成で生じた内部の透過スジと薄い残留画素は、RGBを変えずアルファだけを補正する。右側の黒い陰影は薄くする前の案を採用し、角・頬当て・人物のバランスを保つ。
- 着脱版の黒・赤い鶏冠は、一本角に近い帽体・頬当て・鼻当ての釣り合いへ調整した承認済みパーツを使う。
- 着脱版の黒金・紫は、帽体の前側を控えめに膨らませ、額の下向きのマークと上側の金色の留め具を、仮面の鼻筋に沿う同じ縦軸へ寄せた承認済みパーツを使う。額飾りと周囲の金縁は比較で承認した形を採用し、白い仮面とその眉帯・目・顎・羽飾り・人物の位置は保持する。留め具付近の薄い残留画素と羽飾りの縁は、RGBを維持してアルファのみ補正する。比較試案の青い中心線は公開画面へ追加しない。
- 着脱版の銀・青緑は #153 の承認済みパーツを使う。帽体の頭頂・前後の曲線、太めの額帯、襟足の銀板を整え、銀の鶏冠の台座は帽体に沿わせて少し低くした形を採用する。画像切替版の接続形へ寄せた取消案は使わない。頬・顎当ての形と下端、鼻当て・顔周り・人物を維持し、青緑の羽飾りのバランスを保ち、比較ページ・保存PNG・兜単体サムネイルへ反映する。元の全身画像切替版は別素材を維持する。
- 全6兜で後ろ髪と髪の根元の補正を描かず、人物素材に残っていた襟足側の髪片も共通の装備時人物画像から除去済みとする。首・肩の形と体格、兜の意匠は保持する。兜なしと半透明比較は従来どおり元の顔と髪型を使用する。
- サイズ比較ページは基準の顔と各兜の顔周りを同じ座標・倍率で並べる。通常表示と元の顔への半透明表示、頭頂・額・後頭部・耳側・鼻先・目・顎・兜の端の基準線のON/OFFを切り替えられる。ラベル文字のON/OFFは別に切り替えられ、初期表示では線・文字ともに表示する。線を隠すと文字も隠れて文字切替を無効にし、線を再表示したときは文字の選択状態を保つ。ラベルは「頭頂」「額」「後頭部」「耳側」「鼻先」「目」「顎」「兜の端」とし「（目安）」を付けない。「後頭部」「耳側」「鼻先」「兜の端」の文字は、画像上端の対応する縦線の位置に沿って左からこの順に置く。文字が画像に重ならないよう上側にラベル欄を設け、小さな枠でははみ出さず折り返す。文字や線の非表示時も上側欄の高さを保ち、画像の上下位置を変えない。基準線は表示サイズによらず一定の太さで重ねる。頭頂は髪を含む目安。額の横線は目から顎までと同じ距離だけ目の上に、後頭部の縦線は比較枠の左端と耳側の線の中間に置く。兜の端の縦線は、鼻先から比較枠右端までを3等分した鼻先寄りの位置に置く。いずれも補助的な目安で、実際の頭蓋骨の輪郭を確定するものではない。線は兜ごとに動かさない。
- 比較対象は着脱版と同じ装備データから取得する。新しい兜を装備データへ追加すると、比較画面にも名前・画像が反映される。通常の合成処理も着脱版と共通にする。比較ページから装備画像を編集する機能は設けない。
- 画像ごとの腰・足裏の基準を使って表示位置と大きさを調整する。スマートフォンでも操作できる。
- PCの2列表示では、選択肢をスクロールしてもプレビューが画面内に追従する。スマートフォンの1列表示は通常のページスクロールとする。
- 兜のパーツ合成は比較用の着脱版で提供する。武器・防具の着脱、モーション、戦闘判定は未実装。
- 組み合わせページは、背景透過のキャラ（TADALA、MARCUS MARIUS AVITUS、BERENICE、CASSIA、GOLD HILDR、VLATTIA、SPATALIA、KRIMHARTH、BRANTHOC、TUKHORIS、KASOS、THALES、KHNUBA、MEDOCUS、GAIUS PONTIDIUS STOLO、SALOMON、AMBILLUS、EATHYROSS、AKILIAS、IGRAINE）と背景（海、雪原、草原、森、湿地、山、街、洞窟、松と金雲、鶴と青海波、桜と金屏風、竹と金月、梅と金の雪、富士の裾と金雲、鯉と滝、紅葉と金流水、大聖堂のバラ窓、ゴシック尖頭アーチ、中世グリザイユ、夜の大聖堂、藤とトンボ、バラ園アーチ、海と帆船、ケルト結び目、孔雀の羽、葡萄と秋の葉、蓮と水、星座の円環）を1つずつ選び、背景の上にキャラを重ねて表示する。初期表示はTADALA×海。表示中の組み合わせを512×512のPNGとして保存できる。素材はキャラ・背景とも512×512で揃え、位置や大きさの調整はしない。背景はwebp（画質90は仮置き）で置き、PNGなどで受け取った背景は変換する（#182 でユーザーが決定）。装備室の女性剣闘士とは別の素材で、兜の着脱とは連動しない。キャラ・背景の選択欄はそれぞれ1行に並べ、はみ出した選択肢は横スクロールで選ぶ（#178 でユーザーが決定。#172 の「4列のまま行を増やす」方針を置き換える）。PCでは選択肢を3つ半（右の列が狭い幅761〜960pxでは2つ半）、幅760px以下の1列表示では4つ半が見える大きさにし、右端の欠けで続きを示す（見える数・欄の余白6pxは仮置き）。横スクロール欄の画面外にあるサムネイルも最初に読み込む。選択欄のサムネイルには256×256の縮小画像を使い、合成と保存には512×512の元画像を使う（#166、大きさ・画質は仮置き）。
- 既存の棒人間サンプルのコードは残るが、公開ページと公開用ビルドには読み込まない。

# グラディウス+パルムラ × グラディウス+パルムラ のモーション検証

## 1. 今回の範囲

**双方とも、右手にグラディウス、左手にパルムラを保持する。この組み合わせだけを検証する。**

- 他の武器・盾、盾なし、素手の打撃・掴み・組技は対象にしない。検証中に持ち替えたり、手放したりして空き手を作らない。
- 目的は「攻撃→防御→結果後の双方の姿勢→次の攻防」というモーションのつながりを点検すること。動く試作・実装・画像制作より先に行う。
- 今回の初稿では剣による基本攻撃と、剣・盾による防御、回避から整理する。パルムラでの打撃・押し等、この装備内の他の動作は未整理であり、検証対象から除外・不採用と決めたものではない。
- 以下の動作・組み合わせは**候補**。条件上の矛盾を点検したことと、身体的に成立する・相手に対応できることは区別する。

## 2. モーションの候補一覧

左右は、その動作をする本人から見た左右。各動作の開始時の向きを基準にする。双方とも同じ候補一覧を使い、役割を入れ替えても装備は変えない。

| 攻撃候補 | 剣の動き | これから具体化すること |
|---|---|---|
| 突く | 剣先を対象へ進める | 対象の高さ、剣先と腕の始点・終点、踏み込み、引き戻し |
| 左へ斬る | 本人の右側から左側へ振る | 高さ・斜めの角度、刃の向き、振り抜いた後の剣と盾 |
| 右へ斬る | 本人の左側から右側へ振る | 高さ・斜めの角度、切り返す前の動き、振り抜いた後の剣と盾 |

| 防御候補 | 区別して調べる動き | これから具体化すること |
|---|---|---|
| 盾で受け止める | パルムラで攻撃線を遮る | 先に接触する剣の部位と盾の位置、止まる対象、盾と腕の反動 |
| 盾でそらす | 相手の剣を上／本人の右／本人の左へそらす候補を別々に調べる | 盾の経路と角度、相手の剣と腕がどちらへ動くか、接触を離すまで |
| 剣で受け止める | 右手のグラディウスで受ける | 接触する剣の部位、双方の剣と右腕、左手の盾の位置 |
| 剣でそらす | 相手の剣を本人の右／本人の左へそらす候補を別々に調べる | 交差する剣、そらした後の剣先、反撃へ移るまで |
| 後方へ避ける | 本人の後方へ移動する | 後退の余地、残る攻撃軌道、双方の間合い |
| 右へ避ける | 本人の右へ移動する | 移動中も残る攻撃軌道、双方の位置・向きと剣・盾 |
| 左へ避ける | 本人の左へ移動する | 右回避とは別に、双方の位置・向きと剣・盾 |

高さ・強さ・方向を全て掛け合わせてモーション数を増やす段階には進まない。この一覧も網羅性や個々の技の採用を確認したものではない。

## 3. 最初の点検：Aの胴への突きにBが対応する

A・Bは二人の剣闘士。開始時は向かい合い、両者の保持は §1 のまま。足位置・間合い・剣と盾の具体位置・時刻は未設定なので、ここでは結果が生じたと**仮定**して次の条件を調べる。Bが攻撃する場合も別途照合し、同じ装備だから成功が保証されるとはしない。

| 仮定する結果 | Aが次に行う候補と必要な移行 | Bが次に行う候補と必要な移行 | 今回分かったこと／未確認 |
|---|---|---|---|
| 盾でAの剣の前進が止まる | 接触を離し、剣を引き戻して再び突く | 盾の位置を保って突く候補 | 停止した位置から突きの始点へ瞬時に戻す接続は不可。Aの右腕・身体も止まるか、接触が続くか、双方の腕・剣・盾の経路と反応時間は未確認 |
| 盾との接触でAの剣が戻る側へ動く | 戻る剣から左斬り／右斬りへ移る候補を比較 | 盾と右剣を整え、突く候補 | 止まった場合と戻りの動きが違う。どちらの斬りへつながるか、Bが間に合うかは未確認 |
| 盾でAの剣が上へそらされる | 上がった剣から斬りへ移る候補 | 盾の接触を続ける／離して反撃する候補を分ける | 剣が上にあるだけで下への攻撃を成立としない。Bの盾とAの剣の接触・双方の右腕の経路は未確認 |
| 盾でAの剣がB本人の右へそらされる | そらされた位置から斬りへ移る候補 | 移動後の盾の位置から防御を続ける／反撃する候補 | 向きが変わらなければBの右はAの左側。接触中の向き直り・剣の動き・接続の成否は未確認 |
| 盾でAの剣がB本人の左へそらされる | 前行と別の始点・動きから斬りへ移る候補 | 前行と別の盾の位置から防御を続ける／反撃する候補 | 向きが変わらなければBの左はAの右側。右そらしの単純な左右置換で接続を決めない |
| Bが後方へ避け、突きが当たらない | 剣を戻す。次の突きには距離に応じた踏み込み等が必要か点検 | 後退後の位置から突く／距離を保つ候補 | 後退したことだけでは回避成功にならず、届かない距離からの反撃も成立としない。実際の到達は未確認 |
| Bが本人の右へ避け、突きが当たらない | 相手の移動先へ剣を向ける／斬りへ移る候補 | 移動後の向きを整え、突く候補 | 向きが変わらなければBの移動先はAの左側。元の突きが残る軌道と、両者の向き直りは未確認 |
| Bが本人の左へ避け、突きが当たらない | 前行と反対側の相手へ剣を向ける／斬りへ移る候補 | 移動後の向きを整え、突く候補 | 向きが変わらなければBの移動先はAの右側。左右の装備は反転せず、右の剣・左の盾のまま点検 |

表の各行は排他的な結果分類ではない。「停止後に戻される」「そらされながら戻る」等は時間経過・複合結果として追い、それぞれの時点から次の動作を点検する。これらの実動作も未検証。表は発生し得る結果を網羅していない。防御が間に合わない、盾を外れて身体へ届く、武器・盾に途中で再接触する場合も未検証のまま残す。どの防御がどの結果を生むかは、名称だけでは決めない。

## 4. 確認結果

**今回の文書・条件の点検**
- ✅ 全候補で双方の装備を固定し、自由な左手を前提とする動作を使っていない。
- ✅ 止まる／戻される／上・右・左へそらされる／後・右・左へ避けられる場合を分け、双方の次の候補を併記した。結果の発生確認ではない。
- ✅ 本人基準の左右を整理した。向かい合い、向きを変えないという条件付きで、Bの右側はAから見た左側になる。
- ✅ 接触を同時に維持・解除する指定や、停止位置から無時間で始点に戻る指定を成立扱いしていない。

**まだ検証できていないこと**
- 具体的な姿勢・足位置・間合い・剣と盾の経路・時刻がないため、身体的な成立性、実際の接触、防御成功、直接接続できる次の一手は未確認。
- 斬りへの防御、剣を使った防御、A/Bの役割を入れ替えた具体的な場面は未着手。§3の8分岐を確認済みの連続技として使わない。
- 既存データにはグラディウス攻撃24セットとパルムラ防御3セットがあるが、旧モデルのもの。独立した左右の腕脚や平面上の左右移動、結果別の接続をそのまま検証できるものではない。既存テストの成功を本稿の成立確認に使わない。

## 5. 次に決めること（提案、未承認）

**最初に具体化する一組として「胴への突き→パルムラで上へそらす」を推奨する。** 剣が上がった後から次の攻撃・防御へつながるかを、一場面で比較しやすいため。懸念は、上へそらす動き自体の成立が未確認なこと。成立を前提に先へ進まず、まず両者の開始姿勢から接触後までの剣・盾・身体の経路を点検する。

この一組の選択を確認してから具体的な姿勢・経路を追加する。今回はこの初稿までとし、他の装備や未承認の技へ検証範囲を広げない。
